# Playlist Maker

Курсовая по «Проектированию и разработке мобильных приложений». Приложение ищет музыку через iTunes Search API и помогает собирать свои плейлисты.

## Что умеет

- искать треки и запоминать последние запросы
- добавлять треки в избранное и в плейлисты (плейлисту можно поставить обложку)
- подбирать плейлист по жанрам и настроению с учетом любимых жанров из профиля
- искать по избранному без интернета
- хранить профиль: имя, аватар, любимые жанры и настроение
- переключать светлую и темную тему

## На чем написано

Kotlin и Jetpack Compose, архитектура MVVM. Данные хранятся в Room и DataStore, запросы к iTunes идут через Retrofit, зависимости подключаются через Koin.

## Как запустить

Открыть папку в Android Studio, дождаться синхронизации Gradle и запустить конфигурацию `app` на эмуляторе или телефоне с Android 10 и новее.
